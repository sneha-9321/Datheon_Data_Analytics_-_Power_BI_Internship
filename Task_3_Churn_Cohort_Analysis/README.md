# Task 3: Customer Cohort & Churn Analytics

- `Task3_Churn_Cohort_Analysis.ipynb`: full analysis with outputs (cleaning, cohorts, retention matrix, retention curves, drivers, high-risk segments)
- `Churn_Analysis_Report.md`: written report with charts and retention recommendations
- `images/`: chart images used in the report

**Result in one line:** 26.5% baseline churn, driven by month-to-month contracts, a weak first year, fiber customers without support add-ons, and electronic check payment. The highest-risk segment (month-to-month, fiber, no tech support, no online security) churns at 60.7%.
